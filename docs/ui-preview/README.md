# 简账 UI 预览

这是依据首版需求制作的独立交互原型，不是 Android 安装包。所有账单、金额、通知和权限状态都是演示数据。

直接使用浏览器打开同目录的 `index.html` 即可，无须安装依赖或联网。支持手机与桌面浏览；顶部可切换“交互体验”和六屏“页面总览”。

## 设计取舍

- 首页优先展示本月支出，收入、净支出和上月同期作为辅助信息。
- 底部中央固定“记一笔”，和四个页面入口放在同一条导航中，避免浮动按钮挡住账单金额。
- 已记账与待核对分开；待核对显示原因和明确操作，不提前计入统计。
- 分类、月份与图表可进入对应明细；新增、编辑、删除及撤销实时更新统计。
- 采集设置把通知授权和实际连接分开展示，演示暂停时仍可手工记账。

## 可体验的流程

1. 点击底部“记一笔”，填写金额和分类，保存一次即完成；可同时建立商家分类规则。
2. 打开账单详情，编辑或删除；删除后点击提示中的“撤销”恢复。
3. 在“待核对”对比重复通知、补充金额、确认收支，或忽略无关记录。
4. 在“统计”切换近半年/近一年、分类或自选日期；点击图表进入相同范围的明细。
5. 在“采集与设置”体验授权关闭/连接暂停、规则启停与原文保留选项。

交互结果仅写入当前浏览器的演示存储键，不读取真实通知、不连接支付平台。顶部“重置演示”只重置本原型的数据，支持即时撤销。

首版范围仍为通知采集与手工增改删；没有退款账务、导入、导出、用户备份恢复、OCR 或无障碍服务实现。本次没有修改 Android 工程源码。
